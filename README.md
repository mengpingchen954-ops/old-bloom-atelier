# 旧物生花 · The Bloom Atelier

一间把旧日故事编入丝线的 3D 浏览器发饰工坊。首版为**传统缠花启发的手作 + 花朵发夹**，包含三份可完成的订单。

## 开始试玩

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5198/ 。也可双击 Windows 的 `start-game.cmd`（首次需联网安装依赖）。已安装 Node.js 22.12+ 或 24。

```sh
npm test
npm run build
npm run preview
# 服务器运行时，用本机 Chrome 实际操作验证：
npm run test:browser
npm run test:extended # 通关测试生成样例备份后，验证替代方案与恢复
```

`npm run preview` 地址 http://127.0.0.1:4198/ 。正式构建完全静态，资源使用相对路径，支持 GitHub Pages 仓库子路径。运行时没有第三方网络资源、账号、后端或付费服务。

## 玩法

1. 在来信页检查旧物、选择保留部分、预览并确认清理。旧珠和旧黄铜花托是有限部件，保留来源、金纹 / 氧化斑和用途。
2. 选材料、配色并裁一片芯。左键沿纸芯刷过，只有实际经过的区域绕上线。退线可局部修正。
3. 绕线达 95% 后整形。拖动或滑杆改变弧度；选择圆瓣、尖瓣、叶形。可复制已完成花瓣、移动、旋转、叠层和均匀排列。
4. 清理好的旧珠可接入花心或作垂饰。垂饰位置会改变实际重心。
5. 在台面单击对齐底座，确认后逐个绑扎。没有完成的花瓣、未绑扎、连接距离过远的部件不能通过检查。
6. 试戴使用同一份作品数据。调整佩戴位置、播放指定活动，约 3 秒后记录检查；可暂停、从侧面和背面观察；“翻面查连接”抬起同一作品以直接检查夹背。
7. 教学订单先试戴原先偏左的固定点，发现不稳定，再返回修改、同条件复测。固定点移向花心，或更换支撑更强的双点夹，能降低偏转。如果提前做好了稳定结构，可使用“教学：试戴旧夹的原固定点”补完对比。
8. 条件通过后命名、交付、收款并开启下一封来信。审美偏好不是隐藏配方。收藏可重开为付料副本，下载照片为当前 3D 渲染 PNG。

右键旋转镜头、滚轮缩放；左键加工或移动。Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+S 保存、Esc 取消当前工具。触屏以单指加工和双指观察；完整验收以桌面鼠标为基准。

## 内容与数据

- 一个 3D 木桌、线轴、纸芯、针线与剪刀、材料碗；一套局部头部、发型与受控活动。
- 三种材料配置、三种轮廓、六色、两类固定底座；最多 22 个部件。
- 林阿姨的青瓷旧珠、小满的轻盈散步夹、许老师的旧黄铜花托三份原创订单。
- 分别计算连接、装饰重量、总重心、力矩、底座支撑和佩戴位置。是可解释的游戏规则，不是工程 / 安全认证。
- 库存、金币、订单解锁、作品、加工覆盖、旧物来源、连接、活动检查和收藏统一保存在 localStorage；撤销和重做同步还原库存。
- 自动保存与失败提示；“手作札记”可导出 / 校验导入整份存档。收藏上限 30 件。浏览器本地存档受网址和隐私模式影响，请下载备份。
- 免费轻芯练习材料避免资源死局，拆下部件可回收材料；同一作品只结算一次。

## 文件

- `src/state.js`：作品、库存、订单、连接与试戴计算、存档校验、历史。
- `src/scene.js`：Three.js 场景、参数曲面、纹理、拾取、活动、照片。
- `src/main.js`：工具手势、阶段流程、UI、存档与经营。
- `tests/state.test.js`：经济、规则与数据验证。
- `tests/playthrough.mjs`：真实鼠标 / 键盘端到端试玩，只读取诊断投影坐标，不直接填满制作进度。
- `.github/workflows/pages.yml`：`npm ci`、规则测试、生产构建、GitHub Actions Pages 发布。

详见 [工艺与引用边界](docs/REFERENCE.md)、[实际验收](docs/QA.md)、[原创美术](docs/ART.md)。没有任意雕刻、逐根丝线、完整头发物理，也没有实现绒花 / 簪子 / 抓夹。
