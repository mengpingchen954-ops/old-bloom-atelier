## 核对结果与边界

| 内容 | 已查证 / 未查证 | 本版采用 |
|---|---|---|
| 绒花 | 蚕丝熟绒、染色、退火黄铜丝、绒条与组装有上述报道支持 | 不实现绒花；也不把纸芯刷线标作绒花 |
| 缠花 | 已查到丝线缠花饰品与地方技艺的可靠报道 | 选定传统缠花启发的手作 |
| 芯材与工具 | 本次资料不足以逐项确认特定流派的纸板厚度、铜丝规格、剪刀 / 镊子使用与完整关键工序 | 纸芯、细支撑丝、绕线、受控弧度、组合、绑扎是明确标注的游戏实现，没有宣称正式教学 |
| 材料配置 | 轻芯棉线、丝线纸芯、旧布包芯不是本次资料认证的某流派三种标准配方 | 三套游戏配置具有不同重量、成本、光泽；旧布包芯属于原创改饰方案 |
| 试戴 | 没有工程实验或真实安全认证 | 按材料重量、加权重心与支撑范围计算风险，再驱动受控偏转 / 滑移动画 |

因此产品标题与文案使用**“传统缠花启发的手作”**，不标注国家级 / 省级认证，不指定未经核实的传承流派；不把原创花夹称为已确认的非遗标准成品。游戏的资料边界也在“手作札记”中提供。

## 游戏操作简化

- 纸芯轮廓预设为圆瓣、尖瓣、叶形。纸芯准备以一次裁芯选择代替实际裁剪。
- 24 区离散覆盖替代逐圈丝线绕制；鼠标实际位置决定哪个区域被覆盖。退线、撤销、重做可修正。
- 参数曲面控制弧度、展开与层次，不模拟真实铜丝塑性、剪绒、烫绒和逐根纤维。
- 旧物只能预定义保留整体 / 去扣，保留件的纹理和来源进入实际作品。不是任意切割。
- 有效绑扎以确认的底座、覆盖率和根部连接距离判断；游戏内坐标单位不换算真实工程长度。
- 三种活动采用固定振幅，偏转和滑移由作品数据计算；不存在真实头发碰撞。

## 原创

工坊、角色、来信、报酬、库存、作品名称、花形搭配、模型、贴图、图标、音效与规则均为本版原创。没有敌人、武器或战斗系统，因该题材不需要这些内容。没有额外生成与玩法无关的资产。
