# 美术资源与技术

采用奶油纸色、旧木、藕荷粉、青瓷绿与哑金的原创微缩工作室方向。Three.js 物理光照、环境反射、软阴影与局部接触阴影。

全部视觉资源为项目内原创程序生成：

- 有正反面和厚度的参数化花瓣，圆瓣 / 尖瓣 / 叶形三种轮廓；24 个覆盖区、72 道可见线纹、局部退线和可调卷曲 / 展开。
- 纸芯、棉线、丝线和旧布使用不同粗糙度、丝绸光泽与 Canvas 纹理。
- 旧青瓷珠用带磨损斑和金裂纹的 Canvas 贴图，主体和旧扣可保留或拆分；旧黄铜托以齿状边缘和绿色氧化斑辨认。
- 发夹包括底板、夹片、铰链、防滑垫与双点配置，绑扎线按真实连接位置生成。
- 原创局部头部、发型、髻、发丝及受控活动。不包含真人照片或肖像。
- 木纹、丝线纹理、陶瓷裂纹、接触阴影为本地 Canvas；界面图标和 favicon 为原创 SVG。
- 点击音为 Web Audio 合成音，可关闭；没有音频下载或付费服务。

本会话没有可调用的 imagegen 工具，未运行 imagegen，未使用 AI 位图生成服务或外部美术包。遵照用户允许的程序化替代方案完成全部可运行美术，不将参考网页图片接入产品。不是照片扫描级写实材质；目前为有微表面与真实光照的可爱微缩风格。

性能：合并相邻花瓣材质区、缩减线轴环数量、静态阴影按变更刷新；DPR 最大 1.7；活动时更新阴影；重建作品时释放几何体与材质。未引入完整物理引擎。
